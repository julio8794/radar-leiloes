# Radar de Leilões

Mapa nacional de leilões: imóveis da Caixa, veículos dos Detrans, bancos, Superbid, Mega Leilões e leiloeiros oficiais.
Os lotes estão num só lugar, com filtro por cidade e raio, consulta à Tabela FIPE e calculadora de lucro.

**Acesse:** https://julio8794.github.io/radar-leiloes/

Os dados são atualizados automaticamente a cada 2 dias a partir de páginas públicas. Cada lote leva ao anúncio oficial: confirme preço, regras e edital no site do leiloeiro antes de dar lance.

O roteiro de atualização está em `LEIA-ME.md`.
